# 牛来：牛市接接乐

一个无需后端、无需构建步骤的 Canvas 接物小游戏。红色代表上涨、绿色代表下跌；接红股、躲绿股，积满牛气触发 8 秒“牛市来了”模式。

## 本地运行

在项目目录启动任意静态服务器，例如：

```powershell
npx serve .
```

随后访问命令输出的网址。不要直接双击 HTML 文件：部分浏览器会限制本地资源加载。

## 操作

- 桌面：`←` / `→` 或 `A` / `D`
- 手机与鼠标：按住游戏画面后横向拖动
- 页面切至后台会自动暂停；音效按钮会保存本机选择。
- 首次点击“开盘”后，背景音乐会从音频第 15 秒开始播放，并在曲目末尾回到第 15 秒循环。

## GitHub Pages 部署

1. 将整个项目提交并推送至仓库的 `main` 分支。
2. 在 GitHub 的 `Settings → Pages` 中选择 **Deploy from a branch**。
3. 选择 `main` 与 `/(root)`，保存并等待发布。

资源均使用 `./assets/` 相对路径，因此可在仓库子路径 GitHub Pages 中正常加载。

## 分享图

结算页点击“生成分享图”会按本局指数、称号、得分、最高连涨和牛市次数生成一张 `1080 × 1440` PNG 战报。预览页可点击“保存到本地”下载。

二维码区域目前是清晰标注的占位框；待 GitHub Pages 地址确定后，可将其替换为由实际游戏 URL 生成的二维码。

## 素材

原始精灵表保留在 `assets/character/niulai-actions.png` 与 `assets/items/market-items.png`。游戏使用 `processed/` 中的透明切片，不覆盖原始文件。
